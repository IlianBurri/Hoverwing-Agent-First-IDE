## What's new in 0.9.1

**Linux AppImage starts again.** 0.9.0 crashed on start on systems with an older glibc (for example Ubuntu 24.04: "Failed to load native module: pty.node"). The AppImage is now built on Ubuntu 22.04 and runs on that and newer, and the build checks this from now on.

**Up to four agents at once.** Each agent gets its own tab in the agent panel, with its own permission questions. A file with a held change is locked for the other agents, and restoring a checkpoint while agents are working asks first.
