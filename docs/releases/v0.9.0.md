## What's new in 0.9.0

**Language servers.** Completion, hover, go to definition and a Problems list from real language servers – TypeScript (downloaded via npx on first use), Pyright, rust-analyzer, gopls or your own. Agents can read the current problems through the `get_diagnostics` tool.

**Git panel.** Stage, unstage and discard per file or section, commit with Ctrl+Enter, switch or create branches, fetch, pull and push, and see diffs side by side. Changed files are marked in the file tree; the status bar shows the branch.

**Restricted mode for new projects.** Language servers and Git can run code from a project (tsserver plugins, hooks, filters). They only do so after you trust the project in a native dialog; until then Git only reads.

**Your layout.** Any command as a toolbar button (Pull and Push are there by default), sidebar and agent panel on either side, hide what you don't use, save layouts – or describe the IDE you want and let your chat model propose it, with a preview and Undo.

**Fixes.** Local Ollama models in the chat no longer claim to be a company's assistant; the Linux AppImage builds again; more reliable tests on CI.
