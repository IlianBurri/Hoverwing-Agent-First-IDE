Website privacy

This page is about this website. What the Hoverwing app itself connects to is described in the app privacy statement.

Who runs this website

This website belongs to the open-source project Hoverwing, maintained by IlianBurri. It is non-commercial: nothing is sold and there are no ads. Contact: GitHub issues of the project.

No cookies, no tracking

The website sets no cookies, uses no analytics or tracking, no fonts or scripts from other services and no embedded content (videos, social media buttons).

Hosting: GitHub Pages

The website is hosted on GitHub Pages by GitHub, Inc. (USA). When you open it, your browser sends the usual technical data (such as your IP address, the page requested, date and time, browser and operating system) to GitHub, which may log it for security and operations. See the GitHub General Privacy Statement.

Download buttons: GitHub API

To show the newest version on the download buttons, your browser asks the public GitHub API (api.github.com) for the latest release. This request also goes to GitHub with the technical data above. Without JavaScript the buttons simply link to the releases page. Downloads themselves come from GitHub Releases.

Your rights

The project itself does not collect or store personal data through this website. For data GitHub processes, you can contact GitHub as described in their privacy statement. For questions about this website, open an issue.
