What Kestrel does

Agents with guard rails

Start Claude Code, Gemini CLI or any ACP agent in your project. See its plan, tool calls and answers live; approve commands once or always; stop it at any time. Optionally in a Docker sandbox.

Diff review & checkpoints

Agent edits are held until you accept them – per file or per section. Before every turn Kestrel saves a checkpoint, so any change can be undone.

Bring your own AI

Use your own agent, an OpenRouter or OpenAI-style key, or a local model through Ollama or llama.cpp. The setup assistant detects your hardware and recommends models.

A real editor

Monaco editor, language servers (completion, go to definition, problems), Git panel, terminals, project search, Docker panel and an integrated browser.

Your layout

Any command as a toolbar button, panels on either side, saved layouts – or describe the IDE you want and let your model propose it, with a preview and undo.

Chat & autocompletion

A built-in chat without file access unless you attach a file, and ghost-text completions from a small local model.

Safe by default

  • Ask first: every risky agent action goes through one permission system with an audit log.
  • Secrets stay secret: .env files and keys are never shown to agents or sent to models; API keys live in your system keychain.
  • Restricted mode: language servers and Git only run code from a project after you trust it.
  • No telemetry, no account. Kestrel does not sell or proxy AI usage.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation. (Application in progress; until it is approved, the Windows installers are unsigned.) Only binaries built by GitHub Actions from the public repository are signed, and every release is approved by hand. Roles and details: code signing policy.

Privacy: this program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Exceptions, both can be turned off: the update check on start (GitHub) and the first download of the TypeScript language server (npm). Privacy statement.
