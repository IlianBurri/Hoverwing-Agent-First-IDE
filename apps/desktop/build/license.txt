Kestrel – license and privacy

PRIVACY
Kestrel has no telemetry, no analytics and no account. It only connects to
other systems when you use a feature that needs it (your model provider, an
agent, an MCP server, the integrated browser, Docker, git fetch/pull/push,
GitHub sign-in, the setup assistant). Two connections happen without such a click:

- Update check: on start, the installed app asks GitHub (github.com) whether a
  newer version exists. Nothing is downloaded without your click. Turn it off
  with "Turn off automatic update check" in the command palette (Ctrl+K).
- TypeScript language server: the first time you open a TypeScript or
  JavaScript file in a project you trusted, Kestrel downloads the language
  server from the npm registry (registry.npmjs.org). Turn it off in the
  command palette under "Language servers".

Full privacy statement: https://github.com/IlianBurri/Kestrel-Agen-Harness-IDE/blob/HEAD/PRIVACY.md

Uninstall: Windows Settings > Apps > Installed apps > Kestrel > Uninstall.
Your settings stay in %APPDATA%\Kestrel; delete that folder to remove them.

Code signing: free code signing provided by SignPath.io, certificate by
SignPath Foundation.
